Luz automática por movimiento con Arduino

Un prototipo con dos sensores infrarrojos y seis LED que forman un efecto de «viborita» en cuanto detectan movimiento.

Resumen del proyecto

Se diseñó y construyó un prototipo de iluminación automática armado sobre una protoboard. Una placa Arduino lee dos sensores infrarrojos: si detecta el sensor izquierdo, los seis LED se encienden uno tras otro de izquierda a derecha; si detecta el derecho, el efecto va de derecha a izquierda. El proyecto parte de la propuesta del canal EAZYTRONIC (una luz de escalera automática) y se adaptó con fines académicos.

Arduino, sensores infrarrojos, LED y automatización de la iluminación.

Leer los sensores y controlar el efecto de los seis LED.

Probar

Verificar el funcionamiento, registrar resultados y proponer mejoras.

Cómo funciona

1

Detecta

Los dos sensores infrarrojos perciben la presencia.

2

Decide

Arduino lee los pines 2 y 3 y elige el sentido.

3

Enciende

Los LED se encienden uno tras otro, 70 ms cada uno.

4

Apaga

Cada LED se apaga al pasar al siguiente.

Código

Si un sensor detecta con nivel alto en vez de bajo, cambie LOW por HIGH en la línea de ese sensor.

// Luz automática por movimiento: efecto "viborita" con dos sensores
const int sensorIzq = 2;   // Sensor izquierdo
const int sensorDer = 3;   // Sensor derecho
const int leds[] = {8, 9, 10, 11, 12, 13};  // LED 1 (izq.) a LED 6 (der.)
const int numLeds = 6;

void setup() {
  pinMode(sensorIzq, INPUT);
  pinMode(sensorDer, INPUT);
  for (int i = 0; i < numLeds; i++) {
    pinMode(leds[i], OUTPUT);
  }
}

void loop() {
  int estadoIzq = digitalRead(sensorIzq);
  int estadoDer = digitalRead(sensorDer);

  // Sensor izquierdo detecta algo: efecto de izquierda a derecha
  if (estadoIzq == LOW) {
    efectoViboritaIzqADer();
  }
  // Sensor derecho detecta algo: efecto de derecha a izquierda
  if (estadoDer == LOW) {
    efectoViboritaDerAIzq();
  }
}

// Efecto de izquierda a derecha
void efectoViboritaIzqADer() {
  for (int i = 0; i < numLeds; i++) {
    digitalWrite(leds[i], HIGH);
    delay(70);
    digitalWrite(leds[i], LOW);
  }
}

// Efecto de derecha a izquierda
void efectoViboritaDerAIzq() {
  for (int i = numLeds - 1; i >= 0; i--) {
    digitalWrite(leds[i], HIGH);
    delay(70);
    digitalWrite(leds[i], LOW);
  }
}

Demostración

Pruebas realizadas: reposo sin presencia, activación con cada sensor (la luz recorre los LED en el sentido de ese sensor), ambos sensores a la vez y repetición. Alcance de detección medido: de 3 a 5 cm.

Aplicación social y comercial

Seguridad

Una luz que se enciende sola al detectar movimiento ayuda a ver en la oscuridad, por ejemplo en pasillos o escaleras, sobre todo a niños y adultos mayores.

Ahorro de energía

Las luces se encienden solo cuando alguien las necesita, una idea respaldada por estudios sobre iluminación automática (Ashafa et al., 2023; Durmus et al., 2022).

Bajo costo

Con componentes básicos se arma un sistema funcional; para una instalación real se pueden usar sensores PIR y tiras LED de 12 V con MOSFET.

Mejoras posibles

Sensores PIR de mayor alcance, un sensor de luz para que solo actúe de noche y tiras LED de 12 V para una instalación real.
